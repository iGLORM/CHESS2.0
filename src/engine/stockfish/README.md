# Stockfish (bundled engine)

`stockfish-18-lite-single.js` / `.wasm` are the single-threaded "lite" build of
[Stockfish.js 18](https://github.com/nmrugg/stockfish.js), a WebAssembly port of
[Stockfish](https://github.com/official-stockfish/Stockfish).

Stockfish is free software licensed under the GNU General Public License v3
(see `COPYING.txt`). It runs as a separate program inside a Web Worker and the
game talks to it only through the text-based UCI protocol. Its complete source
code is available at the links above. If you distribute this game, keep this
file and `COPYING.txt` with it and link to the Stockfish source.
